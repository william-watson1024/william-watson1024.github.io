数学基础

0.1 线性代数基础

  1. 向量、矩阵、张量

    • 向量（Vector）：一维数组，表示一个数值集合，例如 [x1, x2, x3]。常用于表示特征或输入数据。
    • 矩阵（Matrix）：二维数组，行表示样本，列表示特征，或用于线性变换。
    • 张量（Tensor）：多维数组，三维或更高维度。神经网络中的数据（图片、视频等）通常表示为张量。

  2. 矩阵运算

    • 加法/减法/数乘：矩阵的元素逐一进行运算。
    • 矩阵乘法：不同于逐元素乘法，是线性变换的核心。若 ( A ) 是 ( m \times n )，( B ) 是 ( n \times p )，则 ( AB ) 是 ( m \times p )。
    • 转置：交换行和列，记作 ( A^T )。
    • 逆矩阵：如果 ( A^{-1} ) 存在，满足 ( A A^{-1} = I )（单位矩阵）。

  3. 特殊矩阵

    • 单位矩阵 (I)：对角线为 1，其他为 0，在乘法中相当于“1”。
    • 对角矩阵：只有对角线有值，其他元素为 0。

核心理解：矩阵是数据和线性变换的表示方式，神经网络中每一层的权重本质上就是一个矩阵。

0.2 微积分基础

  1. 函数导数与偏导数

    • 一元函数导数：表示函数在某点的瞬时变化率，图像上就是切线斜率。
    • 多元函数偏导数：当函数有多个输入变量时，偏导数表示某一变量变化时对输出的影响。

  2. 链式法则（Chain Rule）

    • 当一个函数由多个函数嵌套组成时，求导需要逐层传递梯度。例如神经网络的层与层之间梯度传递就是链式法则的应用。

  3. 梯度与梯度下降

    • 梯度：向量，指向函数上升最快方向。
    • 梯度下降：沿梯度反方向更新参数，使损失函数最小化，是神经网络训练的核心方法。

核心理解：神经网络训练就是通过梯度下降，不断调整参数，让预测结果逼近真实值。

0.3 概率与统计基础

  1. 基本统计量

    • 均值（Mean）：数据的平均水平。
    • 方差（Variance）：数据的离散程度。
    • 标准差（Std）：方差的平方根，更直观表示离散程度。

  2. 概率分布

    • 正态分布：数据集中在均值附近，呈钟型曲线。
    • 均匀分布：每个值出现概率相等，分布平坦。

  3. 损失函数基础

    • 均方误差 MSE：预测值与真实值差的平方平均，适合回归任务。
    • 交叉熵 Cross-Entropy：衡量分类预测的概率分布与真实分布差距，适合分类任务。

核心理解：统计学帮助我们理解数据分布和误差性质，损失函数则是衡量模型预测与真实数据差距的标准。

神经网络基础

神经网络概念

神经元（Neuron）

  • 模拟生物神经元的计算单元。
  • 输入：一组特征 (x_1, x_2, \dots, x_n)。
  • 权重：每个输入对应一个权重 (w_1, w_2, \dots, w_n)。
  • 偏置：一个额外的偏移量 (b)。
  • 输出：先求线性组合，再通过激活函数：
    [
    z = \sum_{i} w_i x_i + b
    ]
    [
    a = \sigma(z)
    ]

层（Layer）

  • 神经元的集合。
  • 全连接层（Fully Connected / Dense Layer）：
    每个神经元与上一层的所有神经元相连。
    [
    \mathbf{a}^{[l]} = \sigma(\mathbf{W}^{[l]} \mathbf{a}^{[l-1]} + \mathbf{b}^{[l]})
    ]

网络结构

  • 输入层 → 隐藏层 → 输出层。

  • 例：2 层全连接网络

    • 输入层：特征数 (n)
    • 隐藏层：(m) 个神经元
    • 输出层：分类数 (k)

激活函数（Activation Function）

激活函数 公式 优点 缺点 使用场景
Sigmoid ( \sigma(x) = \frac{1}{1 + e^{-x}} ) 输出范围 (0,1)，可表示概率 梯度消失，训练慢 二分类输出层
ReLU ( f(x) = \max(0,x) ) 计算快，梯度稳定 ( x < 0 ) 梯度为 0，死神经元 隐藏层最常用
Tanh ( \tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}} ) 输出范围 (-1,1)，均值为 0，收敛快 梯度消失 隐藏层，可代替 Sigmoid

损失函数（Loss Function）

衡量模型预测 ((\hat{y})) 与真实标签 ((y)) 的差距。

  1. 均方误差 MSE（主要用于回归）
    [
    L = \frac{1}{N} \sum_{i=1}^{N} (\hat{y}_i - y_i)^2
    ]

  2. 交叉熵 Cross-Entropy（主要用于分类）
    [
    L = - \sum_{i=1}^{N} y_i \log \hat{y}_i
    ]

优化与梯度下降（GD / SGD）

  • 目标：最小化损失函数 ((L))
  • 梯度下降（GD）：
    [
    \theta \gets \theta - \eta \frac{\partial L}{\partial \theta}
    ]
  • 随机梯度下降（SGD）：
    • 每次用一个样本更新参数，训练更快，增加随机性。
  • 学习率 ((\eta))：
    • 太大 → 发散
    • 太小 → 收敛慢

卷积神经网络基础

卷积层（Convolutional Layer）

核心概念

  • 卷积核（Kernel / Filter）：一个小矩阵（如 (3 \times 3) 或 (5 \times 5)），用来提取局部特征。
  • 输入图像：通常是二维（灰度）或三维（彩色 RGB）数组。
  • 卷积操作：滑动卷积核，计算局部区域的加权和：
    [
    Z[i,j] = \sum_{m}\sum_{n} X[i+m, j+n] \cdot K[m,n] + b
    ]
  • 输出特征图（Feature Map）：卷积后得到的结果。
  • 参数共享：同一个卷积核在整个输入上滑动，减少了参数数量。

卷积层参数

参数 含义
核大小（kernel size） 如 (3 \times 3), (5 \times 5)
步长（stride） 卷积核滑动的步长
填充（padding） 输入边界填充，使输出尺寸可控（valid / same）
通道数（channels） 输入通道数 / 输出特征图数

激活函数

卷积层输出一般也会经过非线性激活函数，例如：

  • ReLU：( f(x) = \max(0,x) )
    → 保持稀疏性、加快训练

池化层（Pooling Layer）

  • 作用：下采样，减少计算量和过拟合，同时保留主要特征。
  • 常见类型：
    • 最大池化（Max Pooling）：取局部最大值
    • 平均池化（Avg Pooling）：取局部平均值
  • 参数：
    • 池化窗口大小（如 (2 \times 2)）
    • 步长（通常等于窗口大小）

全连接层（Fully Connected Layer）

  • 卷积层 + 池化层提取特征后，通常通过全连接层进行分类。
  • 输入为扁平化的特征向量：
    [
    \mathbf{a}^{[l]} = \sigma(\mathbf{W}^{[l]} \mathbf{a}^{[l-1]} + \mathbf{b}^{[l]})
    ]

这个就是经典的 LeNet-5 架构。

层 输出形状

卷积神经网络各层输出公式

1. 卷积层 (Convolution Layer)

[
\text{Conv输出} = \left( \frac{a - m + 2p}{s} + 1 \right) \times \left( \frac{b - n + 2p}{s} + 1 \right) \times k
]

  • (a, b, c)：输入特征图尺寸
  • (m, n, k)：卷积核尺寸和数量
  • (s)：步长（stride）
  • (p)：填充（padding）

2. 池化层 (Pooling Layer)

[
\text{Pool输出} = \frac{a_\text{in}}{s_p} \times \frac{b_\text{in}}{s_p} \times c_\text{in}
]

  • (a_\text{in}, b_\text{in}, c_\text{in})：输入特征图尺寸
  • (s_p)：池化窗口大小（stride通常等于窗口大小）

3. 扁平化层 (Flatten Layer)

[
\text{Flatten输出} = a_\text{in} \cdot b_\text{in} \cdot c_\text{in}
]

  • 将多维输入展开为一维向量

4. 全连接层 (Fully Connected Layer)

[
\text{FC输出} = n_\text{out} \quad (\text{输入向量长度：} n_\text{in})
]

  • (n_\text{in})：输入向量长度
  • (n_\text{out})：输出向量长度

5. 输出层 (Output Layer)

[
\text{Output输出} = K \quad (\text{类别数})
]

  • (K)：分类任务中的类别数

递归神经网络基础（RNN）

1. RNN 概念

  • RNN 用于处理 序列数据（如时间序列、文本、语音）
  • 每个时间步的输出不仅依赖当前输入，还依赖 上一时刻隐藏状态

递归单元公式

隐藏状态更新：
[
h_t = \sigma_h \big( W_{xh} x_t + W_{hh} h_{t-1} + b_h \big)
]

  • (x_t)：当前时间步输入
  • (h_{t-1})：上一时间步隐藏状态
  • (W_{xh}, W_{hh})：权重矩阵
  • (b_h)：偏置
  • (\sigma_h)：激活函数（如 tanh 或 ReLU）

输出：
[
y_t = \sigma_y \big( W_{hy} h_t + b_y \big)
]

  • (y_t)：当前时间步输出
  • (W_{hy})：输出权重矩阵
  • (\sigma_y)：输出激活函数（如 softmax）

2. RNN 网络结构

输入序列：
[
x_1, x_2, \dots, x_T
]

隐藏状态序列：
[
h_1, h_2, \dots, h_T
]

输出序列：
[
y_1, y_2, \dots, y_T
]

  • 每个隐藏状态 (h_t) 都共享权重 (W_{xh}, W_{hh}, W_{hy}) → 参数复用特性

3. 激活函数

激活函数 公式 使用场景
Tanh (\tanh(x)) 隐藏状态输出，范围 [-1,1]
ReLU (\max(0, x)) 隐藏状态，避免梯度消失
Softmax (\frac{e^{x_i}}{\sum_j e^{x_j}}) 分类输出层

4. 损失函数（Loss Function）

  • 分类任务：交叉熵
    [
    L = - \sum_{t=1}^{T} \sum_{i=1}^{K} y_{t,i} \log \hat{y}_{t,i}
    ]

  • 回归任务：均方误差（MSE）
    [
    L = \frac{1}{T} \sum_{t=1}^{T} (\hat{y}_t - y_t)^2
    ]

递归神经网络结构示例（Elman RNN）

1. 典型 RNN 结构

  • 序列长度 (T=3)，输入维度 (D=2)，隐藏层维度 (H=4)，输出维度 (O=2)

输入序列: x1, x2, x3 (T x D)
↓
循环隐藏层: h1, h2, h3 (H)
↓
输出层: y1, y2, y3 (O)

各层输出形状

层 输出形状
输入层 T x D
RNN隐藏层 T x H
输出层 T x O

2. 循环隐藏层 (RNN Layer)

隐藏状态计算公式：
[
h_t = \sigma_h \big( W_{xh} x_t + W_{hh} h_{t-1} + b_h \big)
]

  • (x_t)：当前时间步输入 (1 x D)
  • (h_{t-1})：上一时间步隐藏状态 (1 x H)
  • (W_{xh})：输入到隐藏权重矩阵 (D x H)
  • (W_{hh})：隐藏到隐藏权重矩阵 (H x H)
  • (b_h)：隐藏层偏置 (1 x H)
  • (\sigma_h)：激活函数（tanh / ReLU）
  • 输出形状：1 x H

3. 输出层 (Output Layer)

输出计算公式：
[
y_t = \sigma_y \big( W_{hy} h_t + b_y \big)
]

  • (W_{hy})：隐藏到输出权重矩阵 (H x O)
  • (b_y)：输出层偏置 (1 x O)
  • (\sigma_y)：输出激活函数（softmax / 线性）
  • 输出形状：1 x O
