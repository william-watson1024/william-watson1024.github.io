元组（tuple）

特点

  • 元组用 () 定义，元素不可修改。
  • 支持索引、切片、遍历等操作。
  • 可用于函数返回多个值的场景。

Python 常用模块与文件操作

random — 随机数模块

常用函数：

函数 说明
random.randint(a, b) 生成 a 到 b 的随机整数（包含 b）
random.random() 生成 0~1 之间的随机小数
random.choice(seq) 从序列中随机选择一个元素
random.shuffle(seq) 就地打乱序列顺序

os — 操作系统接口

常用函数：

函数 说明
os.getcwd() 获取当前路径
os.mkdir(name) 创建文件夹
os.rename(old, new) 重命名文件或目录
os.listdir(path) 列出指定目录的内容

os.path — 路径操作工具

常用函数：

函数 说明
os.path.exists(path) 判断路径是否存在
os.path.join(a, b) 拼接路径
os.path.basename(path) 提取文件名
os.path.dirname(path) 提取目录路径

math — 数学函数库

常用函数：

函数 说明
math.sqrt(x) 平方根
math.sin(x) 正弦（弧度）
math.cos(x) 余弦（弧度）
math.pi 圆周率常量
math.factorial(x) 阶乘

模式 说明
r 读取（文件必须存在）
w 写入（覆盖原内容）
a 追加写入
b 二进制模式
r+ 读写模式

CSV 文件操作

高级用法：推导式、lambda、异常处理、常用内置函数、模块导入

列表推导式

列表推导式可以把循环和条件写在一行内完成，比普通循环更简洁。

生成器表达式

生成器表达式使用 () 而不是 []，适合处理大数据，不会一次性生成整个列表。

lambda 函数

lambda 是匿名函数，用于简短的函数定义。

异常处理

用 try-except 捕获异常，可以防止程序因为错误中断，else 在无异常时执行，finally 总会执行。

常用内置函数

Python 内置函数可以快速处理列表、字符串、数字等常见操作。

模块导入

可以通过 import 导入模块，也可以从模块中导入特定函数。
if __name__ == "__main__" 用于区分模块是被导入还是直接运行。
