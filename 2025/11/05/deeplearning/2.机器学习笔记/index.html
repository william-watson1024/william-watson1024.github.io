机器学习

线性回归

基本概念

回归：预测连续值
分类：预测离散值
例如：预测房价是回归，预测猫狗是分类

线性回归模型公式

$y = w_1x_1 + w_2x_2 + … + w_nx_n + b$

损失函数

用mse均方误差来衡量模型好坏
$L = \frac{1}{m}\sum_{i=1}^{m}(y_i - \hat{y_i})^2$

训练一个线性回归模型

逻辑回归

核心思想

逻辑回归用于分类问题，输出类别概率

逻辑回归模型公式

$P(y=1|X) = \sigma(z) = \frac{1}{1 + e^{-z}}$
其中z=w^TX + b
当z->+∞时，P(y=1|X) -> 1
当z->-∞时，P(y=1|X) -> 0
所以逻辑回归模型输出的是样本属于某个类别的概率

决策边界

通常设定阈值0.5
当P(y=1|X) >= 0.5时，预测类别为1
当P(y=1|X) < 0.5时，预测类别为0

决策树

基本概念

决策树是一种树形结构，用于分类和回归任务。每个节点表示一个特征，每个分支表示一个特征值的取值，每个叶子节点表示一个类别或回归值。

决策树算法

  1. 选择最佳特征进行分裂（如信息增益、基尼系数）
  2. 递归分裂子节点，直到满足停止条件（如达到最大深度或叶子节点纯度足够高）
  3. 剪枝以防止过拟合
  4. 预测新样本时，从根节点开始，根据特征值沿树向下遍历，直到到达叶子节点，输出对应的类别或回归值
  5. 决策树的优点：易于理解和解释，处理非线性关系，适用于分类和回归任务
  6. 决策树的缺点：容易过拟合，对噪声敏感，可能不稳定（小变化可能导致树结构大变）

训练决策树模型

概念 含义
决策树 像 if-else 一样划分数据空间
节点分裂 按最优的特征值划分（信息增益最大）
叶子节点 存放预测结果
过拟合 树太深、分得太细
控制复杂度 用 max_depth, min_samples_split 等参数

超参数调节

参数 作用
max_depth 树的最大深度
min_samples_split 一个节点至少要多少样本才可以继续分裂
min_samples_leaf 叶子节点最少样本数
criterion 分裂标准（gini 或 entropy）

随机森林

核心思想

让多棵决策树一起投票，减少过拟合

随机的两点

  1. 样本随机：每棵树用不同的样本子集训练（有放回抽样）
  2. 特征随机：每次分裂只考虑部分特征

训练随机森林模型

超参数调节

参数名 含义
n_estimators 森林中树的数量（越多越稳定，训练更慢）
max_depth 每棵树的最大深度
criterion 分裂标准（gini 或 entropy）
max_features 每次分裂考虑的特征数量（越少越随机）
bootstrap=True 是否使用有放回的样本采样

特征重要性

和决策树对比

对比项 决策树 随机森林
模型类型 单棵树 多棵树的集合
是否随机 否 是（样本 + 特征）
是否易过拟合 ✅ 容易 ❌ 不容易
可解释性 很强 略弱（因为太多树）
预测稳定性 差 很稳定
