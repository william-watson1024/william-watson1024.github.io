3.计算 FIRST 集

FIRST 集是指在文法中，某个非终结符或产生式的第一个终结符集合。计算 FIRST 集的基本规则如下：

  1. 对于终结符 a，FIRST(a) = {a}。
  2. 对于非终结符 A，如果 A → ε 是一个产生式，则 ε ∈ FIRST(A)。
  3. 对于非终结符 A，如果 A → α1α2…αn 是一个产生式，则：
    • 如果 α1 是终结符，则 FIRST(A) 包含 α1。
    • 如果 α1 是非终结符且 FIRST(α1) 不包含 ε，则将 FIRST(α1) 中的元素加入 FIRST(A)。
    • 如果 FIRST(α1) 包含 ε，则继续检查 α2，直到找到一个不包含 ε 的非终结符或到达末尾。
    • 如果所有的 α1, α2, …, αn 都包含 ε，则 ε ∈ FIRST(A)。

4.计算 FOLLOW 集

FOLLOW 集不包括 ε
FOLLOW 集是指在文法中，某个非终结符后面可能出现的终结符集合。计算 FOLLOW 集的基本规则如下：

  1. 对于文法的开始符号 S，FOLLOW(S) 包含 $。
  2. 对于产生式 A → αBβ，如果 β 不为空，则将 FIRST(β) 中的元素加入 FOLLOW(B)。
  3. 如果 β 为空或 FIRST(β) 包含 ε，则将 FOLLOW(A) 中的元素加入 FOLLOW(B)。
  4. 对于产生式 A → αB，如果 B 是文法的最后一个符号，则将 FOLLOW(A) 中的元素加入 FOLLOW(B)。

5.计算 SELECT 集

SELECT 集是指在 LL(1) 分析中，用于选择产生式的集合。计算 SELECT 集的基本规则如下：

  1. 对于产生式 A → α，如果 α 是一个终结符，则 SELECT(A → α) = {α}。
  2. 如果 α 是一个非终结符且 FIRST(α) 不包含 ε，则 SELECT(A → α) = FIRST(α)。
  3. 如果 α 是一个非终结符且 FIRST(α) 包含 ε，则 SELECT(A → α) = FIRST(α) ∪ FOLLOW(A)-{ε}。

6.构造 LL(1) 分析表

LL(1) 分析表是一个二维表，用于指导 LL(1) 分析器的操作。构造 LL(1) 分析表的基本步骤如下：

  1. 初始化一个空的 LL(1) 分析表。
  2. 对于每个产生式 A → α，计算 SELECT 集。
  3. 将产生式 A → α 添加到 LL(1) 分析表的相应位置，即表[非终结符, 终结符] = A → α。
  4. 如果某个位置已经有产生式，则文法不是 LL(1) 文法。

LR(0) 文法技巧

1. LR(0) 项集族

LR(0) 项集族是指在 LR(0) 分析中，用于表示文法的状态集合。每个状态包含一个或多个 LR(0) 项，LR(0) 项是形如 A → α·β 的产生式，其中·表示当前分析的位置。

2. LR(0) 项的闭包

闭包操作是指在 LR(0) 分析中，将一个 LR(0) 项集扩展为包含所有可能的 LR(0) 项。闭包操作的基本步骤如下：

  1. 对于每个 LR(0) 项 A → α·Bβ，如果 B 是一个非终结符，则将所有形如 B → γ 的产生式添加到项集中。
  2. 对于每个添加的产生式 B → γ，如果 γ 以非终结符开头，则继续进行闭包操作，直到没有新的项可以添加。

3. LR(0) 项的转移

转移操作是指在 LR(0) 分析中，根据当前状态和输入符号，转移到下一个状态。转移操作的基本步骤如下：

  1. 对于每个 LR(0) 项集 I 和输入符号 a，如果存在 LR(0) 项 A → α·aβ，则将项集 I 转移到一个新的项集 J，其中 J 包含所有形如 A → αa·β 的项。
  2. 如果 J 是一个新的项集，则将其添加到项集族中。

4. LR(0) 分析表

LR(0) 分析表是一个二维表，用于指导 LR(0) 分析器的操作。构造 LR(0) 分析表的基本步骤如下：

  1. 初始化一个空的 LR(0) 分析表。
  2. 对于每个 LR(0) 项集 I 和输入符号 a，计算转移操作。
  3. 将转移后的项集 J 添加到 LR(0) 分析表的相应位置，即表[状态, 输入符号] = J。
  4. 如果某个位置已经有项集，则文法不是 LR(0) 文法。

5. LR(0) 分析过程

LR(0) 分析过程是指在 LR(0) 分析中，根据 LR(0) 分析表和输入符号，进行语法分析的过程。LR(0) 分析过程的基本步骤如下：

  1. 初始化一个空的栈和输入符号序列。
  2. 将初始状态（通常是文法的开始符号）压入栈中。
  3. 根据当前状态和输入符号，从 LR(0) 分析表中查找转移操作。
  4. 如果找到转移操作，则执行相应的操作（如移进、规约等）。
  5. 如果没有找到转移操作，则报错，表示输入不符合文法。

6. LR(0) 分析的移进和规约

移进和规约是 LR(0) 分析中的两种基本操作。

  • 移进：将当前输入符号压入栈中，并转移到下一个状态。
  • 规约：根据 LR(0) 项集中的产生式，将栈顶的符号替换为相应的非终结符，并转移到新的状态。
